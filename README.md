# Digital Yearbook Web 📸

**A Web-Based Digital Yearbook Platform**

Digital Yearbook is a web development project designed to present student profiles, memories, and class documentation in an interactive digital format.

The platform aims to provide an alternative to traditional printed yearbooks through a web-based experience.
